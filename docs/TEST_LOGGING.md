## 测试准备

1. maidquest 目录执行 `gradlew runClient`（或双击桌面 `maidquest-run.bat`）
2. 创造模式取出「委托板」，贴墙放置
3. 生成 1~2 只普通女仆（TLM 蛋），确认她们处于可工作状态（非跟随、非坐下）

- 制造 / 建造委托类型（界面不显示，`isEnabled=false`）
- TLM 原生任务兼容（通用交付型委托 + `preferredTaskUid` 指向 TLM 原生任务），见 `docs/TODO.md`
- 认领女仆被装入魂符或长期离线时，委托可能停留在「已认领」（待做超时回收）
- 技能等级加权（等 maidtown 接入时通过 `IQuestWeightProvider` 叠加）
